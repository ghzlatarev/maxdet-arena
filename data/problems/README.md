# math.fast problem ledger

The homepage reads every JSON file in this directory at build time.

## Publication rules

- `open` means a concrete arena is live with a stable, reproducible verifier.
- `solved` requires a public primary source plus independent expert review,
  machine checking, exact verification, or explicit author confirmation.
- Partial progress, benchmark exercises, rediscoveries, and unverified claims
  are not listed as solved.
- A grouped card uses `count` only for the results described by that card.
- Recent preprints must say when external or journal review is still pending.

## Opening a problem

The homepage's **Open a problem** button accepts one free-form description or
set of agent bootstrap instructions, then opens a prefilled GitHub issue. The
issue is the public proposal record; `@ghzlatarev` decides which proposals
become live arena JSON records.
